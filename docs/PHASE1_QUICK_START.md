# Phase 1 Quick Start Guide

## 🚀 เริ่มต้นใช้งาน Phase 1

Phase 1 เพิ่มฟีเจอร์สำคัญ 3 ส่วน:
1. **ฟอร์มสมัครงานแบบเต็มรูปแบบ** - นักศึกษากรอกข้อมูลครบถ้วนก่อนสมัคร
2. **รายละเอียดงานที่สมบูรณ์** - แสดงเงินเดือน, ระยะเวลา, สวัสดิการ, ที่ตั้ง
3. **Google Maps Integration** - แสดงที่ตั้งบริษัทบนแผนที่

## 📋 สำหรับนักศึกษา

### ขั้นตอนการสมัครงาน

1. **ค้นหาตำแหน่งงาน**
   - ไปที่หน้า "ตำแหน่งฝึกงาน"
   - ใช้ search bar ค้นหาตำแหน่งที่สนใจ
   - กรองตามรูปแบบการทำงาน (On-site, Remote, Hybrid)
   - เรียงตามวันที่หรือจำนวนที่ว่าง

2. **ดูรายละเอียดงาน**
   - คลิกที่ตำแหน่งที่สนใจ
   - ดูข้อมูลครบถ้วน:
     - ค่าตอบแทน (เงินเดือน)
     - ระยะเวลาฝึกงาน
     - วันปิดรับสมัคร
     - สวัสดิการ
     - ข้อมูลติดต่อ
     - ที่ตั้งบนแผนที่

3. **กรอกใบสมัคร**
   - คลิกปุ่ม "ยื่นใบสมัคร"
   - กรอกข้อมูลส่วนตัว:
     - ชื่อ-นามสกุล
     - เบอร์โทรศัพท์ (10 หลัก)
     - อีเมล
     - ที่อยู่
   - กรอกข้อมูลการศึกษา:
     - เกรดเฉลี่ย (GPA 0.00-4.00)
     - สาขาวิชา
     - ชั้นปี
   - เขียนจดหมายสมัครงาน (ขั้นต่ำ 50 ตัวอักษร)
   - ใส่ Portfolio URL (ถ้ามี)

4. **ตรวจสอบและส่ง**
   - ตรวจสอบข้อมูลในหน้า Preview
   - คลิก "ยืนยันส่งใบสมัคร"
   - รอข้อความยืนยัน

5. **ติดตามสถานะ**
   - ไปที่หน้า "ใบสมัครของฉัน"
   - ดูสถานะใบสมัคร
   - ดู GPA, email, phone ที่ส่งไป
   - คลิกลิงก์ portfolio (ถ้ามี)

## 🏢 สำหรับบริษัท

### ขั้นตอนการสร้างตำแหน่งงาน

1. **เข้าสู่ระบบ**
   - Login ด้วยบัญชีบริษัท
   - ไปที่ Company → Internships

2. **กรอกข้อมูลพื้นฐาน**
   - เลือกบริษัท
   - ชื่อตำแหน่ง (เช่น Software Engineer Intern)
   - รายละเอียดงาน
   - คุณสมบัติที่ต้องการ

3. **กรอกรายละเอียดการทำงาน**
   - สถานที่ (เช่น กรุงเทพมหานคร)
   - รูปแบบการทำงาน (On-site/Hybrid/Remote)
   - ประเภทฝึกงาน (Full-time/Part-time)
   - จำนวนที่รับ

4. **กรอกค่าตอบแทนและสวัสดิการ**
   - เงินเดือนขั้นต่ำ (บาท)
   - เงินเดือนสูงสุด (บาท)
   - สวัสดิการ (คั่นด้วยเครื่องหมายจุลภาค)
     - ตัวอย่าง: ประกันสุขภาพ, ค่าเดินทาง, ค่าอาหาร

5. **กรอกระยะเวลา**
   - วันเริ่มฝึกงาน
   - วันสิ้นสุดฝึกงาน
   - วันปิดรับสมัคร

6. **กรอกข้อมูลติดต่อ**
   - อีเมล
   - เบอร์โทรศัพท์
   - LINE ID

7. **สร้างประกาศ**
   - คลิก "สร้างประกาศ"
   - รอข้อความยืนยัน
   - ดูรายการตำแหน่งที่สร้าง

### ดูใบสมัคร

1. ไปที่ Company → Applicants
2. ดูรายการผู้สมัครทั้งหมด
3. ดูข้อมูล:
   - GPA
   - สาขาวิชา
   - ชั้นปี
   - เบอร์โทรศัพท์
   - อีเมล
   - จดหมายสมัครงาน
   - Portfolio (คลิกลิงก์เพื่อดู)

## ⚙️ Configuration

### Google Maps API Key (Optional)

หากต้องการแสดงแผนที่จริง:

1. ไปที่ [Google Cloud Console](https://console.cloud.google.com/)
2. สร้าง API Key สำหรับ Maps Embed API
3. เพิ่มใน `frontend/.env.local`:
   ```
   NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=your_api_key_here
   ```
4. Restart frontend server

## ✅ Validation Rules

### ข้อมูลส่วนตัว
- **ชื่อ-นามสกุล**: Required, 1-200 ตัวอักษร
- **เบอร์โทร**: Required, 10 หลัก, เริ่มต้นด้วย 0
- **อีเมล**: Required, รูปแบบอีเมลที่ถูกต้อง
- **ที่อยู่**: Optional, สูงสุด 500 ตัวอักษร

### ข้อมูลการศึกษา
- **GPA**: Required, 0.00-4.00
- **สาขาวิชา**: Required
- **ชั้นปี**: Required, 1-6

### จดหมายสมัครงาน
- **Cover Letter**: Required, ขั้นต่ำ 50 ตัวอักษร, สูงสุด 2000 ตัวอักษร

### Portfolio
- **URL**: Optional, ต้องเป็น URL ที่ถูกต้อง (http:// หรือ https://)

## 🐛 Troubleshooting

### ส่งใบสมัครไม่ได้
- ตรวจสอบว่ากรอกข้อมูลครบถ้วน
- ตรวจสอบ validation errors (ข้อความสีแดง)
- ตรวจสอบว่าตำแหน่งยังไม่หมดเขต
- ตรวจสอบว่ายังมีที่ว่าง

### แผนที่ไม่แสดง
- ตรวจสอบว่าได้ configure Google Maps API Key แล้ว
- ตรวจสอบว่า API Key ถูกต้อง
- ตรวจสอบว่าเปิดใช้งาน Maps Embed API

### ข้อมูลไม่อัปเดต
- Refresh หน้าเว็บ (F5)
- Clear cache ของ browser
- Logout และ Login ใหม่
